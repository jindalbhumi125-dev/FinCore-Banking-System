# FinCore – Banking System and Transaction Management Database

## Project Overview

FinCore is a banking database management project developed using MySQL. It demonstrates how relational databases can organize banking information and support data retrieval, reporting, and transaction-related operations.

## Objectives

- Organize customer, account, branch, and loan information.
- Establish relationships between related database tables.
- Retrieve information using SQL queries and JOIN operations.
- Analyze account balances using aggregate functions.
- Demonstrate database features such as views, stored procedures, functions, and triggers.

## Technologies Used

- MySQL
- MySQL Workbench
- SQL

## Main Features

- Customer and banking data management
- Account and branch information
- Loan-related records
- SQL queries using joins and aggregate functions
- Summary views for reporting
- Stored functions and procedures
- Trigger-based auditing and transaction-related logic

## Project Structure

- `FinCore_Banking_System.sql` – SQL script for the database project
- `screenshots/` – Screenshots of queries and their outputs
- `README.md` – Project description and documentation

## Project Outputs

The screenshots demonstrate the database structure, customer-account relationships, loan information, account balance analysis, summary views, and selected transaction-related operations.

## How to Run

1. Open MySQL Workbench.
2. Open `FinCore_Banking_System.sql`.
3. Review the database name and SQL statements.
4. Execute the script in the appropriate MySQL environment.
5. Run the example queries to view the outputs.

**Note:** Running the complete script may create or modify database objects and records. Review the statements before executing it on an existing database.

## Conclusion

This project demonstrates the practical use of MySQL for designing a relational banking database, querying connected information, and implementing database programming features for reporting and transaction-related operations.
